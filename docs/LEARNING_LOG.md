# Learning Log

## Concepts Mastered
- **Database Backups & PITR**: Understanding how managed services like MongoDB Atlas and Neon handle disaster recovery (continuous oplog streaming, storage branching) without needing custom bash scripts.
- **Microservice Networking in Prod**: How API Gateways act as internal proxies, and when external Application Load Balancers are required.

## Concepts I Am Still Learning
- **React Unmount Cycle (useEffect)**: Handling state updates that happen exactly as a component is unmounting to prevent ghost alerts/toasts (like the login success bug).
- **Distributed Tracing**: Connecting logs across RabbitMQ, WebSockets, and multiple microservices so we don't fly blind in production.

## Engineering Habits to Improve
- Verifying the length/type of data generated by the backend against the UI inputs *before* writing the UI (e.g., the 4 vs 6 digit OTP mismatch).
- Adding protective checks to `useEffect` dependencies to ignore updates during pending or successful API mutations.

## New Production Topics Introduced
- **Polyglot Persistence**: Managing data consistency across Postgres and Mongo (e.g., using queues to sync writes).
- **Cold Start Problem**: The challenge of personalization engines when a brand-new user signs up with zero history.
- **The Modern Observability Stack**: 
  - **OpenTelemetry**: Vendor-neutral code instrumentation for distributed tracing.
  - **Prometheus**: Time-series database for metric scraping.
  - **Grafana**: Dashboarding and visualization for system health.
